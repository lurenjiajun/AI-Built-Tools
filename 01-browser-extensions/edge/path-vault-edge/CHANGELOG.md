# 版本记录

## 0.4.2

- 增加完整版本记录文件 `CHANGELOG.md`。
- 增加插件内版本记录页面 `changelog.html`。
- 插件弹窗增加“版本记录”入口。

## 0.4.1

- 增强非标准登录按钮识别。
- 支持登录按钮文字中带空格，例如 `登 录`。
- 支持 `li.login-submit`、`div`、`span` 等非 `button` / `a` 登录控件。
- 点击登录按钮时会向上查找登录控件，兼容嵌套结构。
- 解决部分业务系统点击登录后没有触发记录的问题。

## 0.4.0

- 增加类似 Edge 密码管理器的“待提交凭据”逻辑。
- 用户名、密码输入变化时先暂存到后台。
- Edge 默认填充后，即使没有触发输入事件，也会定时扫描并暂存。
- 点击登录、提交表单、按回车或页面跳转后，再将凭据正式保存到加密库。
- 待提交凭据保存在 `chrome.storage.session` 内存存储中，不写入磁盘。
- 降低提交时密码框已被清空、页面已经跳转导致记录失败的概率。
- Edge 默认填充后提交的账号密码也可以记录到插件。

## 0.3.8

- 每次页面加载时强制确认内容脚本已经注入。
- 解决部分页面初始加载时没有内容脚本监听，导致无法捕获输入和提交的问题。
- 提高 Edge 默认填充后记录账号密码的成功率。

## 0.3.7

- 支持记录 Edge 默认填充后提交的账号密码。
- 点击登录、密码框变化、失焦、按回车等场景增加捕获。
- 同一用户名已存在时，优先保留插件中保存的密码，不让 Edge 默认填充覆盖。
- 插件自动填充后增加二次确认填充，避免 Edge 默认填充随后覆盖插件密码。
- 增加鼠标按下捕获，尽量在页面清空密码框之前记录。

## 0.3.6

- 缓存最近一次输入的账号密码。
- 解决页面在提交前清空密码框，导致插件读取不到密码的问题。
- 支持提交时使用最近一次缓存值进行保存。

## 0.3.5

- 增加后台直接检测和填充能力。
- 不再完全依赖页面内容脚本执行填充。
- 页面加载后如果第一次填充失败，会在约 1.2 秒和 3.2 秒后再次尝试。
- 提高老系统、自定义表单和延迟渲染页面的填充成功率。

## 0.3.4

- 点击“填充”后自动关闭插件弹窗。
- 点击“重新自动填充”后自动关闭插件弹窗。
- 填充失败时保留弹窗并显示错误信息。

## 0.3.3

- 修复页面或 Edge 默认密码管理器已经预填时，插件直接跳过自动填充的问题。
- 自动填充前对比现有账号密码和插件保存的账号密码。
- 不一致时使用插件保存的默认账号覆盖。
- 一致时不再重复触发表单事件。

## 0.3.2

- 增加登录后 60 秒自动填充冷却。
- 只对登录类页面自动填充，登录后业务页面不继续自动操作。
- 自动填充不再触发 `change` 事件，减少业务系统循环加载或提交。
- 降低登录后页面一直转圈的概率。

## 0.3.1

- 增加“重新自动填充”按钮。
- 增加“检测当前页面”功能。
- 增加“复制检测结果”，便于排查复杂业务系统。
- 增加“暂停所有页面自动填充”开关。
- 弹窗显示当前插件版本号。

## 0.3.0

- 新应用的“提交时记录”默认开启。
- 默认开启浏览器重启后自动解锁。
- 解锁后的会话密钥保存在 `storage.session` 内存存储中。
- 默认保存一个不可导出的本机 `CryptoKey` 到 IndexedDB，用于浏览器重启后自动解锁。
- 手动点击“锁定”后会清除本机自动解锁密钥。
- 换电脑、清理浏览器数据或卸载扩展后仍需重新输入主口令。

## 0.2.3

- 增强 iframe 和 `about:blank` 子页面支持。
- 支持非标准密码框。
- 支持只读输入框，并在填充时临时解除只读。
- 增强自定义登录按钮识别。
- 修复部分老系统页面无法记录或无法填充的问题。

## 0.2.2

- 增强 iframe 场景下的应用识别。
- 应用标识改用顶层页面 URL，不再被 iframe 自身 URL 误判。
- 支持非标准密码框和只读输入框。
- 支持自定义登录按钮、链接和 `span` 控件。

## 0.2.1

- 移除高频 DOM 监听，改为低频检测。
- 降低老系统页面因为自动填充检测导致卡死的概率。
- 优化页面加载后的自动填充触发。

## 0.2.0

- 新增打开登录页自动填充。
- 新增同一应用多账号选择。
- 新增默认账号设置。
- 新增页面右下角账号选择框。
- 新增按应用开启或关闭自动填充。
- 新增“浏览器重启后自动解锁”的基础支持。

## 0.1.0

- 首个 Edge Manifest V3 插件版本。
- 按 URL 第一层路径区分不同应用，例如 `/TPBidderCS`、`/TPFrameCS`。
- 账号密码使用 AES-256-GCM 加密。
- 主口令使用 PBKDF2-SHA256 派生密钥，默认 600,000 轮。
- 支持手动记录、手动填充、删除记录。
- 支持 Edge `chrome.storage.sync` 同步加密库。
- 支持导出和导入加密备份。
