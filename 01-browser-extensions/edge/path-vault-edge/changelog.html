应用级密码库 - 版本记录

每个版本的主要改动如下。

0.4.2

  • 增加完整版本记录文件 CHANGELOG.md。
  • 增加插件内版本记录页面。
  • 插件弹窗增加“版本记录”入口。

0.4.1

  • 增强非标准登录按钮识别。
  • 支持 登 录 这种带空格的文字。
  • 支持 li.login-submit、div、span 等非标准登录控件。
  • 解决部分系统点击登录后没有触发记录的问题。

0.4.0

  • 增加类似 Edge 密码管理器的待提交凭据缓存。
  • 输入或 Edge 默认填充后先暂存，提交或跳转后再正式保存。
  • 降低密码框被清空或页面立即跳转导致记录失败的概率。

0.3.8

  • 每次页面加载时确认内容脚本已经注入。
  • 提高 Edge 默认填充后记录账号密码的成功率。

0.3.7

  • 支持记录 Edge 默认填充后提交的账号密码。
  • 同一用户名已存在时，优先保留插件内保存的密码。
  • 自动填充后增加二次确认，避免被 Edge 默认填充覆盖。
  • 增加鼠标按下阶段捕获，尽量在密码框被清空前记录。

0.3.6

  • 缓存最近一次输入的账号密码。
  • 解决提交前密码框被清空导致无法保存的问题。

0.3.5

  • 增加后台直接检测和填充能力。
  • 第一次填充失败后会自动重试。
  • 提高老系统和延迟渲染页面的填充成功率。

0.3.4

  • 点击“填充”后自动关闭插件弹窗。
  • 点击“重新自动填充”后自动关闭插件弹窗。

0.3.3

  • 修复页面已经预填时插件跳过自动填充的问题。
  • 插件保存的账号密码优先于 Edge 默认填充。

0.3.2

  • 增加登录后 60 秒自动填充冷却。
  • 只对登录类页面自动填充。
  • 减少登录后页面转圈和循环加载。

0.3.1

  • 增加“重新自动填充”。
  • 增加“检测当前页面”和“复制检测结果”。
  • 增加“暂停所有页面自动填充”。
  • 弹窗显示当前版本号。

0.3.0

  • 新应用默认开启“提交时记录”。
  • 默认开启浏览器重启后自动解锁。
  • 本机保存不可导出的 CryptoKey，用于自动解锁。

0.2.x

  • 新增打开登录页自动填充。
  • 新增同一应用多账号选择。
  • 新增默认账号设置。
  • 增强 iframe、about:blank、非标准密码框和自定义登录按钮识别。
  • 移除高频 DOM 监听，降低页面卡死概率。

0.1.0

  • 首个 Edge Manifest V3 插件版本。
  • 按 URL 第一层路径区分不同应用。
  • AES-256-GCM 加密，PBKDF2-SHA256 派生密钥。
  • 支持手动记录、填充、删除、同步和加密备份。

完整版本记录也保存在插件目录的 CHANGELOG.md 文件中。
