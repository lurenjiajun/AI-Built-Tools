# Path-aware Password Vault（Edge 扩展）

这是一个面向 Edge 的 Manifest V3 浏览器扩展。它解决的问题不是“记录某个 IP 和端口”，而是：

- 同一个主机和端口后面有多个应用，例如：
  - `https://your-host:port/TPBidderCS`
  - `https://your-host:port/TPFrameCS/customframe4bid/login_TP`
- 扩展会把第一个 URL 路径层级作为应用标识：
  - `https://your-host:port/TPBidderCS`
  - `https://your-host:port/TPFrameCS`
- 因此同一个主机和端口下不同应用的账号密码可以分开保存和自动填充。

## 安全模型

- 密码不会明文落盘。
- 所有条目整体使用 AES-256-GCM 加密。
- 加密密钥来自主口令，使用 PBKDF2-SHA256 派生，默认 600,000 轮。
- 主口令不保存、不同步。
- 解锁后的会话密钥只保存在 Edge 浏览器的 `storage.session` 内存存储中；同时会默认保存一个不可导出的本机 `CryptoKey` 到 IndexedDB，用于浏览器重启后自动解锁。
- 扩展默认不显示明文密码，只提供“填充”。
- 新应用的“提交时记录”默认开启，可以在弹窗中按应用关闭。
- 默认在 Edge 浏览器会话内保持解锁，并支持浏览器重启后自动解锁。
- 跨电脑使用依赖 Edge 账号的 `chrome.storage.sync` 同步；同步的数据仍然是客户端加密后的密文。
- 也支持导出/导入加密备份文件，适合不开同步或需要灾备的场景。

## 安装

Edge 的“加载解压缩的扩展”只能选择**文件夹**，不能选择 `.zip` 文件。

1. 打开 Edge。
2. 进入 `edge://extensions/`。
3. 打开右上角“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择这个文件夹，不是选择 zip：
   ```text
   插件目录（该目录下应直接包含 manifest.json）
   ```
6. 选择后，Edge 应该能直接看到 `manifest.json`。
7. 建议刷新已经打开的业务页面，让内容脚本生效。

## 首次使用

1. 打开任意业务系统页面。
2. 点击扩展图标。
3. 设置一个强主口令并确认。
   - 主口令丢失后无法恢复。
   - 不要复用业务系统密码。
4. 默认已经开启“提交时记录本应用”，不需要每个应用手动开启。
5. 默认已经开启“浏览器重启后自动解锁”；如果关闭这个开关，浏览器重启后需要重新输入主口令。

## 日常使用

### 自动记录

1. 解锁扩展。
2. 打开目标应用登录页。
3. 勾选“提交时记录本应用”。
4. 输入账号密码并提交。
5. 扩展会把凭据加密保存到当前应用标识下。

如果页面使用自定义提交逻辑导致自动记录失败，可以在提交前点击扩展弹窗里的“保存当前表单”。

### 自动填充

1. 先解锁一次扩展。
2. 打开目标应用登录页。
3. 如果该应用保存过账号，扩展会自动填入默认账号和密码。
4. 如果同一个应用保存了多个账号，页面右下角会出现账号下拉框，可以切换账号。
5. 扩展只填充，不自动点击登录按钮。
6. 也可以在扩展弹窗里点击“设为默认”或“填充”。

### 应用层级

默认取第一个路径层级：

- `/TPBidderCS/...` → `/TPBidderCS`
- `/TPFrameCS/customframe4bid/login_TP` → `/TPFrameCS`

如果某些系统需要第二个层级区分，可以在弹窗中把“路径层级”改为 2、3 或 4。

## 其他说明

- 自动填充默认开启，可以在扩展弹窗中按应用关闭。
- 如果某个业务系统对自动填充敏感，可以在插件顶部勾选“暂停所有页面自动填充”。
- 同一个应用有多个账号时，可以在页面右下角选择，也可以在弹窗里点击“设为默认”。
- 如果扩展处于锁定状态，打开页面不会自动填充；解锁后会自动尝试填充当前登录页。
- 0.3.0 版本默认开启提交记录和浏览器重启后自动解锁；0.2.3 版本已移除高频繁的页面 DOM 监听，改为低频检测；同时增强 iframe、about:blank 子页、非标准密码框、只读输入框和自定义登录按钮识别，避免部分老系统页面卡死或无法记录。

## 跨电脑

推荐方式：

1. 在两台电脑的 Edge 中登录同一个 Microsoft 账号。
2. 确认 Edge 的扩展/同步功能可用。
3. 安装同一个本地扩展目录，或把整个 `path-vault-edge` 目录复制到另一台电脑后加载。
4. 在任意一台电脑解锁后新增或修改记录。
5. 另一台电脑会通过 `chrome.storage.sync` 收到加密库更新。
6. 如果扩展处于锁定状态，收到更新后不会自动解密；需要用户输入同一个主口令解锁。

备用方式：

- 使用“导出加密备份”。
- 把 JSON 文件复制到另一台电脑。
- 在目标电脑使用“导入备份”。
- 使用原主口令解锁。

## 重要限制

- 这是本地密码管理器，不是隐身凭据采集工具。首次使用需要用户设置并输入主口令。
- “浏览器重启后自动解锁”默认开启。如果电脑被他人使用，建议关闭该开关，或使用后点击“锁定”。
- 本机自动解锁依赖浏览器本机存储；清理浏览器数据、卸载扩展或手动锁定后，可能需要重新输入主口令。
- 如果电脑已有恶意软件、键盘记录器或恶意浏览器扩展，任何密码管理器都无法保证安全。
- 不要在不受信任的公共电脑上解锁。
- `chrome.storage.sync` 有容量限制，通常适合个人使用的几十到上百条记录，不适合当团队密码库。
- 多台电脑同时修改时有覆盖风险；建议避免同时在多台电脑编辑。
- 备份文件仍然需要主口令才能解密，但不要把主口令和备份文件放在同一个位置。
- 如果忘记主口令，没有恢复后门。

## 文件说明

- `manifest.json`：扩展清单和权限。
- `background.js`：加密、解密、同步、自动锁定、条目管理。
- `content.js`：识别登录表单、按需记录、填充。
- `popup.html` / `popup.css` / `popup.js`：用户界面。
